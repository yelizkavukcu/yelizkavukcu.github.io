# Yeliz Kavukcu — Coğrafya Portfolyosu

## İçerik
- `index.html`: Responsive, tek sayfalık kişisel/akademik portfolyo.
- `assets/yeliz-kavukcu.jpg`: Kullanıcının sağladığı portre fotoğrafının web için optimize edilmiş kopyası.

## GitHub Pages ile yayınlama
1. Bu klasördeki dosyaları bir GitHub deposunun kök dizinine yükleyin.
2. GitHub deposunda **Settings → Pages** bölümünü açın.
3. **Deploy from a branch** seçin, `main` dalını ve `/ (root)` klasörünü seçip kaydedin.
4. Birkaç dakika sonra GitHub Pages adresi hazır olur.

## Düzenleme notları
- E-posta ve LinkedIn bilgileri henüz verilmediği için iletişim alanları yer tutucu olarak bırakıldı.
- Tez/rapor dosyaları ve gerçek arazi fotoğrafları henüz verilmediği için akademik kartlar ve galeri açıklama/yer tutucu niteliğindedir.
- İçerikleri `index.html` içinde düzenleyebilirsiniz.
